# Свадебный бот для сбора фото и видео

Бот принимает у гостей фото/видео, спрашивает имя, напоминает про качество
и сохраняет всё в базу данных (SQLite). Опционально дублирует все медиа
в приватный Telegram-канал как резервное хранилище.

## 1. Создание бота

1. Напишите в Telegram боту **@BotFather** → `/newbot`.
2. Задайте имя и username (например, `MyWedding2026Bot`).
3. Скопируйте выданный **токен** — он понадобится в `.env`.

## 2. Установка

```bash
cd wedding_bot
python3 -m venv venv
source venv/bin/activate       # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
```

Откройте `.env` и заполните:
- `BOT_TOKEN` — токен от BotFather
- `ADMIN_IDS` — ваш Telegram user id (узнать у @userinfobot), для команды `/stats`
- `BACKUP_CHAT_ID` — необязательно, см. пункт 4

## 3. Запуск

```bash
python bot.py
```

Бот должен работать постоянно (24/7 на время свадьбы и после неё, пока
гости заливают файлы). Варианты хостинга:
- Небольшой VPS (например, Timeweb, Selectel, Hetzner) — самый надёжный вариант
- Railway.app / Render.com — есть бесплатные лимиты, легко развернуть
- Любой сервер с Python и systemd/screen/tmux, чтобы процесс не завершался

## 4. QR-код

QR-код ведёт на ссылку вида `https://t.me/ВашБот?start=wedding` — гость
сканирует, сразу открывается чат с ботом и жмёт «Старт».

Сгенерировать QR-код:
```bash
python generate_qr.py ВашБот
```
Файл `wedding_qr.png` можно распечатать на приглашениях или табличках.

## 5. Резервное хранилище (рекомендуется)

По умолчанию файлы хранятся только как `file_id` в базе — это ссылки
Telegram на файлы, они не занимают место на вашем диске, но зависят
от Telegram. Чтобы иметь независимую копию всех медиа:

1. Создайте приватный канал в Telegram.
2. Добавьте туда вашего бота как администратора.
3. Узнайте ID канала: перешлите любое сообщение из канала боту
   **@getidsbot** (или временно добавьте туда @userinfobot) — получите
   число вида `-1001234567890`.
4. Вставьте это значение в `BACKUP_CHAT_ID` в `.env`.

Теперь каждое полученное фото/видео бот будет пересылать в канал с
подписью «От: Имя (@username)» — так у вас будет и лента всех фото, и
запись в базе.

## 6. Как это выглядит для гостя

1. Сканирует QR → открывается бот → жмёт «Старт»
2. Бот просит написать имя или юзернейм
3. После имени бот присылает напоминание: отправлять фото/видео **как
   файл (документ)**, а не как обычное фото — иначе Telegram сожмёт
   качество
4. Гость присылает файлы, бот подтверждает приём каждого

Если гость всё же пришлёт как обычное фото/видео (не файлом) — бот всё
равно его примет, но напомнит про способ с файлом на будущее.

## 7. База данных

Данные лежат в `wedding_bot.db` (SQLite), таблицы:
- `guests` — id, telegram_user_id, имя, username, дата регистрации
- `media` — id, guest_id, file_id, тип (photo/video), ссылка на резервную
  копию в канале, дата загрузки

Открыть базу можно любым SQLite-клиентом (например, DB Browser for
SQLite) или скриптом на Python — при желании могу добавить готовый
скрипт экспорта в CSV/Excel или веб-панель для скачивания всех файлов
одним архивом.

## 8. Команды

- `/start` — регистрация / приветствие
- `/stats` — (только для ADMIN_IDS) сколько гостей и файлов уже загружено

## Важно

- Токен бота (`BOT_TOKEN`) никому не показывайте и не публикуйте.
- Пока скрипт `bot.py` не запущен — бот не отвечает. Убедитесь, что он
  работает на выбранном хостинге до и во время мероприятия.
